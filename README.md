# 海外华人博士人才 Sourcing 工具包

把"**在海外 · 华人 · 博士 · 在世界 500 强(AI/医疗/制造/材料)或 QS 前 100 院校做研究 · 或毕业于 QS 前 100 · 最好有回国意愿**"这个目标人群,翻译成可以**直接在 LinkedIn 与 Google 上运行**的检索式,并配一套可照做的 sourcing 打法和参考数据。

> 这是给**做人才寻访 / 海归招聘**的人用的"搜人工具",不是数据抓取程序。

---

## 这是什么 / 不是什么

| ✅ 是 | ❌ 不是 |
|---|---|
| 一套**布尔检索式 + Google X-ray 检索式** | 自动抓取 LinkedIn 的脚本 |
| 一份 **sourcing 打法手册**(漏斗、资格审查、外联) | 一份现成的真实人名清单 |
| 可替换进检索式的**参考数据**(姓氏、公司、院校、回国信号) | 任何"帮你自动加好友/群发"的灰产工具 |

为什么不直接给人名清单:
1. **批量抓取 / 自动化采集 LinkedIn 违反其《用户协议》**,账号会被封,部分法域还有法律风险。
2. 真实个人的姓名与履历**不应由模型凭空生成**——既不可靠(会编造),也涉及隐私。
3. 正确做法是:**你用这套检索式自己跑**,人由你来看、判断、联系。召回质量远高于任何"现成名单"。

## 5 分钟上手

1. 打开 **`queries/query-recipes.md`**,挑一个跟你目标最接近的"配方"(按人群 Persona 1/2/3,或按行业/地区)。
2. 复制其中的 **LinkedIn 检索式** → 贴进 LinkedIn 搜索框,切到 **People(人脉/人物)** 标签;再用左侧 **Location 过滤器**锁定海外地区(美/加/英/欧/新/澳/日…)。
3. 想要更大召回、或没有 Recruiter 账号 → 用 **`queries/google-xray.md`** 的 X-ray 式在 Google 里跑,绕过站内搜索配额。
4. 命中候选人后,按 **`playbook.md`** 的**资格审查清单**逐个核对:华人? 博士? 目标行业/院校? 有没有回国信号?
5. 需要替换检索式里的占位符(院校串、公司串、姓氏串、回国信号词)时,去 **`reference/`** 取。

## 重要前提(动手前必读)

- **合规**:按"华人/族裔"**直接**筛选,在美国等地的雇佣法里属于**受保护特征**,是敏感项。本工具包一律用**可观察的代理信号**(中文姓名拼音、中国本科院校、列了普通话、华人专业社群等)去**近似**,而不是把"种族"本身当录用标准。务必先读 `compliance.md`。
- **平台规则**:遵守 LinkedIn《用户协议》——可以**手动搜索、查看、正常联系**,但不要用脚本批量抓取/加好友。
- **隐私法**:外联与存档需符合候选人所在地法律(欧盟 GDPR、英国 UK-GDPR、中国 PIPL、加州 CCPA 等)。
- **时效**:`reference/` 里的 QS 前 100、世界 500 强清单**每年都会变**,文件内已标注"以官方最新表为准"的位置,使用前请对一遍当年官方榜单。

- QS 排名锚点为 **QS World University Rankings 2026**(MIT 第 1、NUS 第 8、NTU 第 12、北大第 14、清华第 17 等已核对);完整前 100 membership 见 `reference/qs-top100-universities.md`,边界院校(约 90–120 名)请以官方表为准。
- 公司清单对标 **Fortune Global 500 / 各行业公认龙头**,为代表性清单而非穷举,且 500 强成员每年微调。
